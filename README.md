# Titanic Dataset Analysis

## Overview
This project focuses on exploratory data analysis (EDA) of the Titanic dataset using Python and Pandas. It explores the dataset's structure, performs data inspection, and examines passenger information to practice essential data analysis techniques.

## Objectives
- Understand the structure and features of the dataset.
- Perform data inspection.
- Explore passenger information and survival-related patterns.

## Dataset
The Titanic dataset is sourced from the publicly available Data Science Dojo GitHub repository.

**Dataset link:** https://github.com/datasciencedojo/datasets/blob/master/titanic.csv

## Tools and Technologies
- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Project Notebook
The notebook contains the code, analysis, and outputs for the project.

## How to Use
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Download the dataset from the source linked above if it is not already included.
3. Run the notebook cells sequentially to reproduce the analysis.

## Disclaimer
This project is for educational purposes and exploratory data analysis only.
